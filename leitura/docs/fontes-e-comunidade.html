    Onde estudar: fontes e aplicações

    ← Guias · Como estudar · Pesquisar · X e Discord

    Escolha uma leitura principal e aplique no seu agente. Esta curadoria organiza fontes por finalidade; os exercícios são propostas desta trilha. Os catálogos completos são material de consulta, não uma lista de cursos obrigatórios.

    Comece pelos materiais da formação

    Material Quando ler O que fazer depois
    História da IA — ler online Semanas 1 e 4: contexto histórico, conceitos e limites. Explicar qual parte do seu problema precisa de IA e qual pode ser resolvida com regras.
    Base Técnica — ler online Semanas 4–10: consultar o bloco ligado à tarefa atual. Desenhar o caminho de uma entrada pelo sistema e identificar onde pode falhar.

    OpenAI

    Recurso oficial O que estudar Aplicação sugerida
    OpenAI Developers — Learn Guias de construção de agentes e aplicações. Semanas 4–7: seguir um exemplo pequeno e adaptar as entradas ao seu projeto.
    OpenAI Cookbook Exemplos de implementação para uma dúvida concreta. Semanas 5–10: reproduzir um exemplo, alterar uma variável e registrar o efeito.
    Evals — guias e exemplos Como definir e executar avaliações. Semana 9: transformar falhas do agente em casos de avaliação repetíveis.

    Comece por: Learn; consulte o Cookbook quando tiver uma tarefa definida. A documentação do recurso escolhido deve orientar a implementação e a versão da API.

    Anthropic

    Recurso oficial O que estudar Aplicação sugerida
    Claude Academy Fluência em IA, uso de Claude e construção com seus produtos. Semanas 1–4: praticar como delegar uma tarefa e avaliar a resposta.
    Building effective agents Escolhas de desenho entre fluxos e agentes. Semana 7: desenhar onde o fluxo é fixo e onde o modelo pode decidir.
    Claude Platform Docs Integração com a API e uso de ferramentas. Semanas 5–8: conectar uma ferramenta de leitura e verificar seus argumentos.
    Anthropic Engineering Relatos técnicos sobre agentes, contexto e avaliação. Semanas 7–10: escolher um artigo que ajude a investigar uma falha atual.

    Comece por: Academy para fundamentos; para o primeiro agente, leia o artigo de desenho antes de ampliar a autonomia.

    Google

    Recurso oficial O que estudar Aplicação sugerida
    Machine Learning Crash Course Fundamentos de aprendizado de máquina; selecione os módulos necessários. Semana 4: explicar treinamento e inferência e comparar regras com modelo.
    Gemini API — documentação Primeira integração, saídas estruturadas e chamadas de ferramentas. Semanas 5–8: extrair dados de uma entrada e validar o formato antes de agir.
    Google Cloud — treinamento Cursos e laboratórios, conforme a necessidade do projeto. Semanas 8–11: escolher um laboratório relacionado ao ambiente em que vai operar.

    Comece por: um conceito do Crash Course ou o início rápido da Gemini API, conforme sua lacuna. Confira os requisitos de acesso e uso do laboratório escolhido.

    GitHub

    Recurso oficial O que estudar Aplicação sugerida
    Introduction to GitHub — Skills Repositório, branch, commit e pull request. Desde a semana 1: guardar o projeto e revisar uma mudança antes de incorporá-la.
    GitHub Learn Catálogo de aprendizado e guias de produtos. Semanas 3–11: procurar a atividade que atende sua necessidade de colaboração ou automação.
    Git e GitHub — recursos de aprendizado Orientação para estudar controle de versão. Recuperar uma versão e explicar a diferença entre duas entregas.

    Comece por: Introduction to GitHub e aplique no mesmo repositório em que constrói o agente.

    Microsoft

    Recurso oficial O que estudar Aplicação sugerida
    Generative AI for Beginners Lições e exemplos de aplicações com IA generativa. Semanas 4–9: selecionar a lição ligada à entrega e reproduzir um exercício.
    Microsoft Learn em português Módulos e roteiros de aprendizado; busque o tema da semana. Semanas 4–11: estudar um módulo de IA ou operação e aplicar a decisão ao agente.

    Comece por: uma lição de Generative AI for Beginners; use o Learn para aprofundar a parte que precisa agora.

    Como escolher sem acumular abas

    1. Abra a semana atual e leia a entrega.
    2. Escolha uma fonte que responda à decisão mais próxima.
    3. Anote uma ideia e implemente um teste.
    4. Guarde a fonte junto com o experimento.
    5. Use X e Discord para discutir o resultado ou uma dúvida que permaneceu.
